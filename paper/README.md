# ALMS Research Paper — working directory

Draft sections here as Markdown. **Figures and tables are generated by scripts in
`figures/` from real pipeline output — never hand-typed.** Final typesetting is done
in Overleaf with `\documentclass[conference]{IEEEtran}`; copy section prose in and
keep this directory as the source of truth for text and for the reproduction of
every number.

**Rule:** every numeric or comparative claim in the paper must trace to a command in
`build.md`, a generated table in `tables/`, or a generated figure in `figures/`.

## Layout

| Path | Contents |
|---|---|
| `sections/NN-*.md` | one file per paper section; `<!-- STATUS -->` tracks progress |
| `figures/*.py` | generators (run from repo root); `*.pdf`/`*.mmd` are their outputs |
| `tables/*.md` | generated or hand-assembled tables |
| `notes/*.md` | one digest per reference (Phase 2) |
| `refs.bib` | BibTeX; keys fixed in the plan's "reference map" |
| `build.md` | reproduction log — exact commands for every number/figure |

## Workflow

1. Phase 1 (this pass): generate figures/graph stats that need no LLM.
2. Phase 1 (partner): run `main.py` with local Ollama, capture `audit.db` +
   `pipeline_summary.json` + resource samples, then run `figures/gen_metrics_table.py`
   and fill `tables/resources.md`.
3. Phase 2: fill `notes/*.md`, build `tables/related-work-comparison.md`.
4. Phase 3: draft `sections/*.md`.
5. Phase 4: assemble, typeset in Overleaf, reproduce-everything check.
